# Installer Proxmox VE (hyperviseur homelab)

Proxmox VE 9 est un hyperviseur libre basé sur Debian 13 « Trixie ». Il fait tourner des VMs complètes et des conteneurs LXC légers, pilotés depuis une interface web. Ce tuto couvre l'installation **par-dessus une Debian existante**.

<Diagram name="proxmox" />

<Warn>Pour un premier serveur, l'<strong>ISO officielle</strong> est la voie recommandée (elle installe tout, partitionnement compris). L'install sur Debian existante ci-dessous s'adresse à qui veut garder un partitionnement custom.</Warn>

<Automatic>

```bash
# Dépôt no-subscription + noyau Proxmox (à lancer sur une Debian 13 Trixie à jour).
echo "deb [arch=amd64] http://download.proxmox.com/debian/pve trixie pve-no-subscription" | sudo tee /etc/apt/sources.list.d/pve-install-repo.list
wget https://enterprise.proxmox.com/debian/proxmox-release-trixie.gpg -O /etc/apt/trusted.gpg.d/proxmox-release-trixie.gpg
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y proxmox-default-kernel
```

</Automatic>

## 00 — Pré-requis

<Detailed>Une Debian 13 (Trixie) 64 bits à jour, un nom d'hôte résolvable, et un accès root.</Detailed>

<Full>Le nom d'hôte doit pointer vers l'IP fixe de la machine dans `/etc/hosts` — Proxmox refuse de s'installer sinon. Vérifie que `hostname --ip-address` renvoie bien ton IP et pas `127.0.1.1`.</Full>

```bash
hostnamectl set-hostname ${HOSTNAME}
```

<Check id="pve-hosts" cmd="hostname --ip-address" expect="${SERVER_IP}" />

## 01 — Ajouter le dépôt Proxmox

<Detailed>On ajoute le dépôt « no-subscription » (gratuit) et sa clé.</Detailed>

```bash
echo "deb [arch=amd64] http://download.proxmox.com/debian/pve trixie pve-no-subscription" | sudo tee /etc/apt/sources.list.d/pve-install-repo.list
```

```bash
wget https://enterprise.proxmox.com/debian/proxmox-release-trixie.gpg -O /etc/apt/trusted.gpg.d/proxmox-release-trixie.gpg
```

```bash
sudo apt update && sudo apt full-upgrade -y
```

## 02 — Installer le noyau Proxmox

<Detailed>On installe le noyau Proxmox puis on redémarre dessus.</Detailed>

```bash
sudo apt install -y proxmox-default-kernel
sudo reboot
```

<Check id="pve-kernel" cmd="uname -r" expect="-pve" />

## 03 — Installer Proxmox VE

<Detailed>Une fois redémarré sur le noyau Proxmox, on installe le paquet complet.</Detailed>

```bash
sudo apt install -y proxmox-ve postfix open-iscsi chrony
```

<Full>Postfix te demandera un type de configuration mail : « Site Internet » convient, ou « Pas de configuration » si tu n'envoies pas de mails. `open-iscsi` et `chrony` couvrent le stockage réseau et l'horloge.</Full>

<Check id="pve-version" cmd="pveversion" expect="pve-manager/9" />

## 04 — Accéder à l'interface

<Detailed>L'interface web tourne en HTTPS sur le port 8006.</Detailed>

```bash
echo "https://${SERVER_IP}:8006"
```

<Note>Connecte-toi avec l'utilisateur `root` et son mot de passe système. Le certificat est auto-signé : c'est normal que le navigateur prévienne au premier accès.</Note>

## 05 — Retirer le bandeau « subscription »

<Full>Sans abonnement, l'interface affiche un avertissement à chaque connexion. Tu peux supprimer le dépôt entreprise pour éviter les erreurs apt, le reste fonctionne sans licence.</Full>

```bash
sudo rm -f /etc/apt/sources.list.d/pve-enterprise.list
```
