# Pi-hole v6 — DNS anti-pub pour tout le réseau

Pi-hole intercepte les requêtes DNS de **tous** tes appareils et bloque pub et traceurs à la source. La v6 intègre un serveur web et une API REST directement dans le binaire (plus de lighttpd/PHP) et une config unique en TOML. IP du serveur à gauche.

<Diagram name="pihole" />

<Warn>Donne d'abord une <strong>IP fixe</strong> à la machine (réservation DHCP sur ton routeur, ou IP statique) : tous tes appareils pointeront vers cette adresse pour le DNS, elle ne doit pas changer.</Warn>

<Automatic>

```bash
# Installe Pi-hole en mode non-interactif n'est pas recommandé : lance l'installeur guidé.
curl -sSL https://install.pi-hole.net | sudo bash
```

</Automatic>

## 00 — Le principe

<Detailed>Pi-hole est un résolveur DNS : quand un appareil demande l'adresse d'un domaine de pub, Pi-hole répond « 0.0.0.0 » et la pub ne se charge jamais.</Detailed>

<Full>Le blocage se fait au niveau DNS, donc il couvre apps, smart TV et navigateurs sans extension à installer. Le revers : certains domaines mêlent contenu et pub — d'où la liste blanche, gérable depuis l'interface.</Full>

## 01 — Lancer l'installeur

<Detailed>L'installeur officiel détecte ta distribution et te guide (interface réseau, listes de blocage, IP statique).</Detailed>

```bash
curl -sSL https://install.pi-hole.net | sudo bash
```

<Note>À la fin, l'installeur affiche l'adresse de l'interface et un mot de passe temporaire. Note-les.</Note>

<Check id="pihole-status" cmd="pihole status" expect="FTL is listening" />

## 02 — Définir le mot de passe admin

<Detailed>En v6, le mot de passe de l'interface se règle avec une commande dédiée (ou depuis Settings → Web interface).</Detailed>

```bash
pihole setpassword
```

<Check id="pihole-version" cmd="pihole -v" expect="Core version is v6" />

## 03 — Pointer le réseau vers Pi-hole

<Detailed>Dans les réglages DHCP de ton routeur, mets le serveur DNS principal sur l'IP du Pi-hole.</Detailed>

<Full>Le mieux est de changer le DNS au niveau du routeur (DHCP) : tous les appareils en héritent automatiquement. À défaut, configure le DNS appareil par appareil. Pense à renouveler le bail DHCP (ou redémarrer le Wi-Fi) pour que le changement prenne.</Full>

```bash
echo "DNS du routeur -> ${SERVER_IP}"
```

## 04 — Vérifier le blocage

<Detailed>On interroge directement Pi-hole sur un domaine de pub connu : il doit répondre 0.0.0.0.</Detailed>

```bash
dig @${SERVER_IP} doubleclick.net +short
```

<Check id="pihole-block" cmd="dig @${SERVER_IP} doubleclick.net +short" expect="0.0.0.0" />

## 05 — L'interface web

<Full>Ouvre `http://${SERVER_IP}/admin` : tu y vois les requêtes en temps réel, le pourcentage bloqué, et tu gères listes noires/blanches. La v6 propose un mode « Basic » et un mode « Expert » selon ton aisance.</Full>

```bash
echo "http://${SERVER_IP}/admin"
```

<Check id="pihole-web" cmd="curl -sI http://${SERVER_IP}/admin/ | head -n1" expect="HTTP/1.1 200 OK" />
